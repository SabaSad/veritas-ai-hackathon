## How to run

1. Clone the repo:
   ```
   git clone <repo-url>
   cd <repo-folder>
   ```
2. Create and activate a virtual environment:
   ```
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # Mac/Linux
   source .venv/bin/activate
   ```
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Open the notebook:
   ```
   jupyter notebook notebooks/
   ```
